# Changelog

All notable changes to `@r69shabhjs/markdown-doc` are documented here.

## [0.1.0-alpha.2] - 2026-08-12

- Rewrote the README as a comparison-led, search-friendly open-source landing page.
- Added npm keywords and GitHub repository topics for Markdown, mdast, TypeScript, and source preservation.
- Added contribution, security, roadmap, and changelog documentation.

## [0.1.0-alpha.1] - 2026-08-12

- Published the source-preserving Markdown document model under the `@r69shabhjs` npm scope.
- Added frozen mdast access, UTF-16 offset lookup, and localized text edits.
- Added CommonMark, frontmatter, edge-case, and corpus fidelity coverage.
- Added ESM, CommonJS, and TypeScript declaration builds.

## [0.1.0-alpha] - 2026-08-12

- Initial public alpha release.
